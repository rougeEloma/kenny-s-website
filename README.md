# Kenny's International website

`site/` is the static build of the new kennysinternational.com, served by Render (static site, publish path `site`).

- Press articles are static snapshots of the articles published in the dashboard (https://kennys-international.netlify.app/vogin). Re-export after publishing.
- The contact form posts to the Netlify form "contact" (notifications are set in Netlify).
- `kennys-homepage-backup-2026-10-05.zip` is the earlier homepage backup, kept as is.
