# Source of the Kenny's International website

`site/` (at the repo root) is the built website. This folder holds what builds it.
No passwords or secrets are stored here: the dashboard password hashes and the session secret
live only in the Netlify environment variables `KP_USERS` and `KP_SESSION_SECRET`.

## netlify-site/
The Netlify project (site `kennys-international`, https://kennys-international.netlify.app).
- `public/`: built pages, including `vogin.html` (the /vogin dashboard).
- `netlify/functions/`: the backend (logins, articles, photo uploads, server-rendered Press pages).
  Data is kept in Netlify Blobs (stores `kp-articles`, `kp-media`, `kp-users`, `kp-auth`).
- `netlify/functions/_lib/templates.mjs` is generated by the builder; don't edit it by hand.
- Deploy: from this folder with the Netlify CLI or the Netlify MCP deploy command.

## builder/
Python builder for every page (`build3.py`) and the FR | ENG translations.
```
python3 -I builder/build3.py <builder dir> <netlify-site>/public <netlify-site>/netlify/functions/_lib/templates.mjs
```
- `index.base.html`, `franchise_data.py`, `map.svg.txt`, `legal_data.py`: page content.
- `i18n/fr.json`: French dictionary; `i18n/engine.js`: the language switch.
- `hostinger/export.py`: makes the static copy (static Press pages, `api/articles.json`, PHP contact form
  for Hostinger). `site/` in this repo is that copy, with the contact form posting to Netlify Forms instead.
- `api-test.mjs`: backend checks (`node api-test.mjs <url> <password> <image>`).
- `import_old.py`: the one-time import of the old WordPress press articles.
